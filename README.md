## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or launch a quick local server with Python:

```bash
cd "C:\Users\Raina\.gemini\antigravity\scratch\raina-portfolio"
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.

## 🌐 How to Deploy to GitHub Pages or Vercel

### Option 1: GitHub Pages
1. Create a repository named `portfolio` on your GitHub (`github.com/RainaVashishth`).
2. Push this directory to the repository.
3. In GitHub Settings -> Pages, select `main` branch root (`/`) and Save.
4. Your site will be live at `https://rainavashishth.github.io/portfolio/`!

### Option 2: Vercel / Netlify
1. Connect your GitHub repository to Vercel or Netlify.
2. Zero configuration is needed—it deploys automatically in seconds.
